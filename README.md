# Sasak Multi Dialect Dataset
This research develops a machine translation system with multi-dialect output,  using a case study on English to Sasak language. Sasak is a low resource language in Indonesia that contains multiple dialect variations, such as Kuto-Kute (Pemenang), Ngeno-Ngene (Selaparang) Ngento-Ngente (Suralaga), Meno-Mene (Pejanggik), and Mriak-Meriku (Pujut).
